# The acc coprocessor

> The acc 256-bit coprocessor: one big-number accelerator spanning classical (RSA/ECC) and post-quantum work (it also drives SPHINCS+ PQ-secure boot), not a PQC-only unit. Frame it that way so readers are not surprised when RSA/ECC use the same block back in the secure-boot part. Read pavona/hw/ip/acc/doc.
